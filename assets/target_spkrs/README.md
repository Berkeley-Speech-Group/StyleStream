From the project root, download the target speaker package from Hugging Face into this folder:

```bash
hf download Louis0324/StyleStream target_spkrs.tar --repo-type model --local-dir assets/target_spkrs
```

After downloading, this folder should contain:

- `target_spkrs.tar`

If you run the download command from another directory, move `target_spkrs.tar` into `assets/target_spkrs/`.
